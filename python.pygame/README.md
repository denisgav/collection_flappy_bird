To run this example need o install pygame.
1. Pip install option:
    pip install pygame
2. Use virtual environment:
2.1 Clean install
    python3 -m venv .venv
    source .venv/bin/activate
    pip install pygame
    pip freeze > requirements.txt
2.2 Use requirements.txt
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
